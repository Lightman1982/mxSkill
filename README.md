## 家长孩子怎么用

1. 下载对应学科的对话版txt文件。在GitHub文件页点击Download raw file（下载原始文件），不要把网页另存为文件。
2. 打开你准备测试的AI，新建对话，上传该txt。如果不支持上传txt，则打开文件并复制全文到新对话。
3. 发送：请完整阅读附件，按照最后的“启动任务”开始执行；如果无法完整读取，请先告诉我。
4. 按提示选择家长、孩子或讲解，再发题目。三个学科首次测试分别使用三个新对话。

下载文件不会自动安装Skill。标准Skill包解压后包含同名文件夹和SKILL.md，应按照目标工具的技能安装方式导入。普通聊天用户优先使用txt版，不需要上传zip。

## 建议测试

- 新对话启动：是否正确识别学科、询问身份、展示原有备注。
- 回复孩子：是否提供对应学科选项，能否利用兴趣帮助学习。
- 回复家长：是否进入学习诊断或成果检查。
- 直接要答案：是否帮助理解并验证独立掌握。
- 切换身份或跑题：是否适当恢复对应学习规则。
